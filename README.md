# 🌦 Weather Monitoring Station

A simple Arduino project that measures the temperature and humidity of the surrounding environment using a DHT11 sensor. The measured values are displayed on a 16×2 I2C LCD in real time.

---

## 📖 About the Project

This project was made to learn how sensors work with Arduino. It reads temperature and humidity using a DHT11 sensor and shows the readings on an LCD display. The project is easy to build and is a good starting point for beginners who want to learn about Arduino and sensors.

---

## ✨ Features

- 🌡 Displays temperature in real time
- 💧 Displays humidity in real time
- 📺 Uses a 16×2 I2C LCD display
- 🔌 Simple Arduino circuit
- 🛠 Beginner-friendly project
- 💡 Easy to understand and modify

---

## 🧰 Components Used

- Arduino Uno
- DHT11 Temperature and Humidity Sensor
- 16×2 I2C LCD Display
- Breadboard
- Jumper Wires
- USB Cable

---

## 🔌 Pin Connections

| Arduino Uno | Component |
|--------------|-----------|
| 5V | DHT11 VCC |
| GND | DHT11 GND |
| D2 | DHT11 DATA |
| 5V | LCD VCC |
| GND | LCD GND |
| A4 | LCD SDA |
| A5 | LCD SCL |

---

## ⚙️ How It Works

1. The Arduino reads temperature and humidity from the DHT11 sensor.
2. The sensor sends the data to the Arduino.
3. The Arduino processes the data.
4. The temperature and humidity values are shown on the LCD.
5. The readings update continuously after a short delay.
